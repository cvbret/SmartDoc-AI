# Docker 应用与数据指南

镜像是包含应用程序和运行依赖的只读模板。docker build 根据 Dockerfile 构建镜像。容器是镜像的运行实例，具有进程和自己的可写层；docker run 创建并启动容器。

停止容器不等于删除容器。停止后可以用 docker start 再次启动，容器的可写层仍然保留。删除容器会丢失它的可写层，因此不能只把需要长期保存的数据库文件放在那里。

命名卷在容器之外保存数据。把数据库数据目录挂载到命名卷后，删除容器通常不会自动删除该卷；新容器挂载同一卷可以访问保留的数据。显式删除卷仍会使其中的数据丢失。卷不能替代备份。

镜像解决应用及依赖的打包问题，命名卷解决容器生命周期之外的数据保存问题。更换应用镜像并不意味着应删除数据卷。卷的持久性也不等于数据库的一组写操作具有事务原子性。
