# Python 列表排序指南

列表是可变对象。两个变量引用同一个列表时，对这个列表的原地修改会通过两个变量体现出来。

list.sort() 按元素大小对原列表排序，不创建新列表，返回值是 None。不要把它的返回值当成排序后的列表。list.reverse() 仅反转现有顺序，不保证按大小有序，同样原地修改并返回 None。

sorted(iterable) 返回新的已排序列表，保留原列表的内容和顺序。需要同时保存原始顺序和排序结果时，应使用 sorted()。sorted() 也能接收元组等可迭代对象。

sort() 和 sorted() 都支持 key 参数指定比较依据，例如按字符串长度排序可用 key=len；reverse=True 表示按比较依据降序排列。Python 排序是稳定的：比较依据相同的元素保留原来的相对顺序。
